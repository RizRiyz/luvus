---
title: Commander
description: Send prompts or shell commands to exact terminal panes without leaving your current pane.
---

Press **`Ctrl+Space Enter`** (or your configured prefix, then `Enter`). Commander
opens as a persistent composer below the terminal panes. It
does not create a layout leaf or change the selected pane, but it initially
takes keyboard focus so you can type a message. The visible terminal area
resizes while it is open. Drag the shared edge from either the pane above or
Commander's top border to change its height; Commander keeps its default
five-cell minimum. Press the same shortcut to hide it. The
draft disappears when you hide it or another TUI client takes control.

The strip is not modal: prefix shortcuts still change tabs, workspaces, panes,
and other Luvus controls while it stays visible. `Esc` returns keyboard focus
to the selected pane without hiding the strip. Clicking a tab, workspace, or
pane works normally and leaves the draft intact; click the strip to type into
it again. Navigating elsewhere does not silently change its explicit targets.

Mention a live agent by pane ID or Luvus alias to send a prompt. Mention a shell
by pane ID or pane name to run a one-line command:

```text
@p17 review the current diff
@reviewer check the tests
@p24 ls
@p17 @reviewer review this together
```

Here p17 and reviewer are agent panes, while p24 is a shell. A shell target
executes its text as a command, so use a command valid for every selected shell.

The focused terminal pane's `@pID` is filled in when Commander opens.
Exact `@pID` mentions select panes anywhere in the message, including within
the text. A named path can narrow an exact pane through its tab and workspace:

```text
@tab:tests/pane:reviewer check the tests
@workspace:app/tab:tests/pane:p24 ls
```

Names with spaces use percent escaping (for example, `review%20work`). Type
`@tab:` and press `Tab` to pick a tab name, then press `Tab` again to complete
an exact pane; further presses cycle panes in that scope. `Shift+Tab` starts
from the last choice. Bare scopes do not broadcast.
Adjacent mentions before any text share that text. Once text follows a
mention, the next mention starts a separate message for its own target. The
mentions themselves are removed from the delivered text. `=` is not a
Commander target prefix.
Type `@` and press `Tab` to complete it in place to a pane name (or `@pID`
when unnamed). `Tab` and `Shift+Tab` cycle a mention under the cursor. A unique
agent kind such as `@codex` also works; an ambiguous kind requires a pane ID
or alias. `@pane:reviewer` also addresses a named pane. Shells without a pane
name require a pane ID.
Targets can be in another tab or workspace of the **same** named session.
`@session:<current-name>/...` may make the current session explicit, but
cross-session delivery is not supported yet. The title shows recognized exact
panes before you send.

Only recognized pane IDs, aliases, and named paths add inline recipients;
package names such as `@types/node` and arguments such as `=value` remain
prompt text. Prefix a mention with `\` to send it literally, for example
`\@p24`.

To send the same text to several panes, list their mentions together:

```text
@p17 @p24 review the authentication changes
```

To send different text in one submission, put each message after its target:

```text
@p8 Okay, you got it. @p9 ls
```

Here p8 receives only the sentence and p9 receives only `ls`. One `Enter`
sends every segment directly; no confirmation is needed. Each agent receives
a prompt; each shell executes its own text as a command. Shell commands must
be one line, even if the composer contains a newline. Luvus
validates every segment before sending and rechecks each pane, terminal
lifetime, and agent/shell identity at dispatch. It reports each result and
does not retry successful deliveries if another
target fails. Use `Up` and `Down` to inspect receipts. If messages differ or
only some panes receive them, the draft clears to prevent an accidental
resend. A workspace, tab, or session name never expands into a broadcast.
The limit is 16 explicit targets per send.

To split one exact pane, enter a standalone action instead of a message:

```text
@reviewer:sv
@p24:sh
```

`:sv` splits side by side (new pane on the right); `:sh` stacks the new pane
below. Each action opens a new shell beside its target, including a target in
another tab or workspace, then focuses the new pane. Commander stays visible
but gives keyboard focus to that pane. The draft changes to the new pane's
mention, so pressing Enter again cannot repeat the split. An action cannot be
combined with message text or other targets. Named paths also work, for
example `@tab:tests/pane:reviewer:sv`.

## Slash actions

Type `/` at the start of the draft to use a Luvus action. If Commander still
contains its initial `@pID` mention, typing `/` replaces that starter text.
The picker matches Commander's width and lists matching commands, their
purpose, and the selected command's usage while you edit the slash name.
Type more letters to filter. `Up`/`Down`, `PageUp`/`PageDown`, or the mouse
wheel browse the list; click a row to select it. On short terminals the list
scrolls to keep the selected row visible. `Tab` and `Shift+Tab` still complete
or cycle names. `Space` accepts the selection and starts arguments. `Enter`
accepts a selected or partial name, starts required arguments, or runs a
complete action. Use `@` and `Tab` to complete an exact target where required.

```text
/focus @p17
/focus @tab:tests
/focus @workspace:app
/read @p17
/fork @reviewer
/split @p24 right
/split @p24 below
/task
/automation
/mission
/diff
/files
```

`/focus` switches to one exact pane, tab, or workspace without sending input.
`/read` shows a bounded snapshot of one pane's recent output in Commander;
use `PageUp` and `PageDown` to browse it. `/fork` uses the native agent session
fork handler and requires a fork-capable agent with a known session. `/task`
opens the existing task form; the task is created only when you complete that
form. These actions take no free-form message text, and an unknown `/` action
is rejected rather than forwarded to a pane. To send an agent's own slash
command as text, put it after a target, such as `@p17 /status`.

`/split` creates a shell beside one exact pane: `right` places it alongside,
`below` stacks it underneath. `sv` and `sh` are accepted direction aliases.
`/automation` opens the existing automation form; it does not schedule
anything until you finish that form. `/mission` opens Mission Control in the
current workspace. `/diff` and `/files` focus their respective dock views.
These navigation actions do not send terminal input. The picker contains only
actions available in this version of Commander.

`Enter` sends to all listed targets. `Shift+Enter` adds a visible new line;
`Alt+Enter` is a fallback for terminals that cannot report Shift+Enter.
The composer remains open after sending. Pasted clipboard images appear as
`[Image #1]` markers in the draft, while the receiving pane gets the staged
image path. Text and image paste edit the draft only while the strip has
keyboard focus; otherwise they follow the
normal active pane or modal. Outside the slash picker, arrow keys, `Home`/`End`, `Ctrl`/`Alt` word
navigation and deletion, `Ctrl+U`/`Ctrl+K` line deletion, and macOS Command
editing chords work in the draft. `Up` and `Down` move between draft lines
before cycling delivery receipts at the draft boundary. Select text with
`Shift` plus navigation, then copy or cut it with `Ctrl+C`/`Ctrl+X` or Command
equivalents. Paste uses the terminal's normal paste event. A **queued** receipt
means input was submitted atomically, not that the agent task or shell command
has finished.

Commander does not yet approve blocked-agent dialogs or route to another named
session or saved SSH machine. Use the existing controls for those operations.
