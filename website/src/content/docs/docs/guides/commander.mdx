---
title: Commander
description: Send prompts or shell commands to exact terminal panes without leaving your current pane.
---

Press **`Ctrl+Space Enter`** (or your configured prefix, then `Enter`). Commander
opens as a full-width pane-style strip below the terminal panes. It
does not create a layout leaf or change the selected pane, but it initially
takes keyboard focus so you can type a message. The visible terminal area
resizes while it is open. Press the same shortcut to hide it. The draft
disappears when you hide it or another TUI client takes control.

The strip is not modal: prefix shortcuts still change tabs, workspaces, panes,
and other Luvus controls while it stays visible. `Esc` returns keyboard focus
to the selected pane without hiding the strip. Clicking a tab, workspace, or
pane works normally and leaves the draft intact; click the strip to type into
it again. Navigating elsewhere does not silently change its explicit targets.

Address a live agent by pane ID or Luvus alias to send a prompt. Address a shell
by pane ID to run a one-line command:

```text
=p17 review the current diff
=reviewer check the tests
=p24 ls
=p17 review this with @p24
```

In the review examples, p17 and p24 are agent panes. A shell target executes
the text as a shell command, so use a command valid for every selected shell.

The focused terminal pane's `=pID` is filled in when Commander opens.
Add `@pID` mentions before, within, or after the message to select more panes;
they are removed from the delivered text. `=pID` tokens also work anywhere.
`Tab` and `Shift+Tab` add a pane mention at the cursor or cycle a mention the
cursor is on. A unique agent kind such as `=codex` also works as the first
word; an ambiguous kind requires a pane ID or alias. Shells require a pane ID.
Targets can be in another tab or workspace of the **same** named session. The title shows the
recognized targets before you send.

Only exact `@pID` and `=pID` words are pane mentions; package names such as
`@types/node` and arguments such as `=value` remain prompt text. Prefix an
exact mention with `\` to send it literally, for example `\@p24`.

To send the same text to several panes, list each exact target:

```text
=p17 =p24 review the authentication changes
```

One `Enter` sends directly to every listed pane; no confirmation is needed.
Each agent receives a prompt; each shell executes the text as a command. Shell
commands must be one line, even if the composer contains a newline. Luvus
rechecks each pane, terminal lifetime, and agent/shell identity at dispatch,
reports each result, and does not retry successful deliveries if another
target fails. Use `Up` and `Down` to inspect receipts. If only some panes
received the text, the draft clears to prevent an accidental resend. A
workspace, tab, or session name never expands into a broadcast. The limit is
16 explicit targets per send.

`Enter` sends to all listed targets. `Shift+Enter` adds a newline.
The composer remains open after sending. Text and clipboard-image paste edit
the draft only while the strip has keyboard focus; otherwise they follow the
normal active pane or modal. Arrow keys, `Home`/`End`, `Ctrl`/`Alt` word
navigation and deletion, `Ctrl+U`/`Ctrl+K` line deletion, and macOS Command
editing chords work in the draft. Select text with `Shift` plus navigation,
then copy or cut it with `Ctrl+C`/`Ctrl+X` or Command equivalents. Paste uses
the terminal's normal paste event. A **queued** receipt means input was
submitted atomically, not that the agent task or shell command has finished.

This first release does not approve blocked-agent dialogs, invoke `/` actions,
or route to another named session or saved SSH machine. Use the existing
controls for those operations.
