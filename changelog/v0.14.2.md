Luvus v0.14.2 adds pane focus history, Letta Code, OpenCode 2 improvements, stronger ORCH task control, FreeBSD release binaries, and fixes pane clipboard copies from OSC 52 (including Claude Code drag-select). Existing v0.14.1 settings and sessions remain compatible after upgrading.

## Features

- **Input:** Jump back through recent pane focus with keyboard navigation ([`9795793`](https://github.com/RizRiyz/luvus/commit/9795793), [#380](https://github.com/RizRiyz/luvus/pull/380)).
- **ORCH:** Start tasks without stealing focus from the pane you are watching ([`db42239`](https://github.com/RizRiyz/luvus/commit/db42239), [#360](https://github.com/RizRiyz/luvus/pull/360)).
- **Agents:** Detect, monitor, resume, and install the Luvus skill for Letta Code ([`1bff4f8`](https://github.com/RizRiyz/luvus/commit/1bff4f8), [#366](https://github.com/RizRiyz/luvus/pull/366)).
- **Release:** Ship reliable FreeBSD amd64 binaries in CI and release assets ([`63f7df6`](https://github.com/RizRiyz/luvus/commit/63f7df6), [#365](https://github.com/RizRiyz/luvus/pull/365)).
- **OpenCode:** Support the released OpenCode 2 CLI ([`8e20623`](https://github.com/RizRiyz/luvus/commit/8e20623), [#363](https://github.com/RizRiyz/luvus/pull/363)).
- **ORCH:** Retry failed tasks through a safe lifecycle without losing queue state ([`5089c1c`](https://github.com/RizRiyz/luvus/commit/5089c1c), [#348](https://github.com/RizRiyz/luvus/pull/348)).

## Improvements

- **Input:** Preserve complete Kitty keyboard protocol state across nested terminal apps ([`9883032`](https://github.com/RizRiyz/luvus/commit/9883032), [#370](https://github.com/RizRiyz/luvus/pull/370)).

## Fixes

- **Clipboard:** Forward OSC 52 clipboard writes from pane apps to the client so drag-select and TUIs like Claude Code reach the system clipboard ([`3443330`](https://github.com/RizRiyz/luvus/commit/3443330), [#386](https://github.com/RizRiyz/luvus/pull/386)).
- **OpenCode:** Report the selected session on OpenCode 2.0.3 ([`f8ce1c7`](https://github.com/RizRiyz/luvus/commit/f8ce1c7), [#369](https://github.com/RizRiyz/luvus/pull/369)).
- **Input:** Move the text cursor inside rename dialogs instead of leaving it at the edge ([`94a861b`](https://github.com/RizRiyz/luvus/commit/94a861b), [#382](https://github.com/RizRiyz/luvus/pull/382)).
- **Input:** Preserve modified Enter identity for apps that distinguish plain and modified Enter ([`7e70fcb`](https://github.com/RizRiyz/luvus/commit/7e70fcb), [#368](https://github.com/RizRiyz/luvus/pull/368)).
- **ORCH:** Scope tasks and leases to projects so parallel work stays isolated ([`7564b19`](https://github.com/RizRiyz/luvus/commit/7564b19), [#361](https://github.com/RizRiyz/luvus/pull/361)).
- **ORCH:** Deliver multiline task briefings reliably to agent panes ([`561b037`](https://github.com/RizRiyz/luvus/commit/561b037), [#358](https://github.com/RizRiyz/luvus/pull/358)).
- **API:** Include agent aliases in session snapshots for automation and UHP clients ([`decd82e`](https://github.com/RizRiyz/luvus/commit/decd82e), [#300](https://github.com/RizRiyz/luvus/pull/300)).
- **Workspace:** Preserve focus when a workspace opens automatically ([`7346a86`](https://github.com/RizRiyz/luvus/commit/7346a86), [#351](https://github.com/RizRiyz/luvus/pull/351)).
- **IPC:** Read local server messages before sending attach metadata so clients connect cleanly ([`dd5b1bd`](https://github.com/RizRiyz/luvus/commit/dd5b1bd), [#357](https://github.com/RizRiyz/luvus/pull/357)).
- **Sessions:** Recover named sessions after upgrades without leaving stale layout state ([`70bc007`](https://github.com/RizRiyz/luvus/commit/70bc007), [#346](https://github.com/RizRiyz/luvus/pull/346)).
- **Website:** Polish the logo and mobile navigation on luvus.dev ([`38f4b9f`](https://github.com/RizRiyz/luvus/commit/38f4b9f), [#347](https://github.com/RizRiyz/luvus/pull/347)).
