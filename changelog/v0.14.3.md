Luvus v0.14.3 adds Luvus Web, Commander, pane-local search, Arc Studio CLI support, and more extensible modules, with safer agent control and smoother session handling. Existing v0.14.2 settings and sessions remain compatible; restart running servers after upgrading.

## Features

- **Web:** Open your workspaces and terminals in a browser with one-use pairing, read-only access by default, and optional control ([`eea2b2c`](https://github.com/RizRiyz/luvus/commit/eea2b2ce539a7509815e3c311648115b0f52885c), [#403](https://github.com/RizRiyz/luvus/pull/403)).
- **Web:** Attach files and paste images from the browser into a selected terminal pane ([`eea2b2c`](https://github.com/RizRiyz/luvus/commit/eea2b2ce539a7509815e3c311648115b0f52885c), [#403](https://github.com/RizRiyz/luvus/pull/403)).
- **Web:** Pair phones through a trusted HTTPS tunnel and update its address without restarting the bridge ([`cbb1ed4`](https://github.com/RizRiyz/luvus/commit/cbb1ed4c3b627fa3919a49fd4f4b3375bbe4d4fe), [#457](https://github.com/RizRiyz/luvus/pull/457)).
- **Commander:** Send prompts or shell commands to exact panes from a persistent multi-pane command strip ([`732c81c`](https://github.com/RizRiyz/luvus/commit/732c81c61ef331a99e63f8e975ae28aebfb195ac), [#411](https://github.com/RizRiyz/luvus/pull/411)).
- **Commander:** Create tasks and automations or focus, read, fork, and split panes with guided slash actions ([`732c81c`](https://github.com/RizRiyz/luvus/commit/732c81c61ef331a99e63f8e975ae28aebfb195ac), [#411](https://github.com/RizRiyz/luvus/pull/411)).
- **Modules:** Expose opt-in module actions as Commander commands with target selection, confirmation, and execution receipts ([`f34406b`](https://github.com/RizRiyz/luvus/commit/f34406b6046798f0d9d7409953e3045d9a15babe), [#450](https://github.com/RizRiyz/luvus/pull/450)).
- **Search:** Find and highlight text within terminal scrollback, files, DIFF, Markdown, and Mermaid views ([`0c5ac30`](https://github.com/RizRiyz/luvus/commit/0c5ac30cb9e3686a498521fccdafe99feec1bef0), [#414](https://github.com/RizRiyz/luvus/pull/414)).
- **Files:** Fuzzy-filter workspace paths and open file actions directly from the global finder ([`a1d8eea`](https://github.com/RizRiyz/luvus/commit/a1d8eeaf4223eb1eb724e028b84073572f136224), [#388](https://github.com/RizRiyz/luvus/pull/388)).
- **Agents:** Detect Arc Studio CLI and report its working, idle, and login-blocked states ([`7af7c33`](https://github.com/RizRiyz/luvus/commit/7af7c3344ebf692b70b58b06d745ea77ac1171d2), [#407](https://github.com/RizRiyz/luvus/pull/407)).
- **Devin:** Install an optional session hook for exact conversation ownership and resume after a restart ([`76c70ef`](https://github.com/RizRiyz/luvus/commit/76c70ef94ac2cda7832b6ca5a0100c1652b06155), [#416](https://github.com/RizRiyz/luvus/pull/416)).
- **Sessions:** Disable saved terminal screen content while retaining layouts and resumable agent metadata ([`75d8d49`](https://github.com/RizRiyz/luvus/commit/75d8d49686f4fb02ebb6a1a89315ccacd626e0f7), [#401](https://github.com/RizRiyz/luvus/pull/401)).
- **Workspaces:** Copy a workspace's root path or Git branch from its Quick Actions context submenu ([`b1f09c7`](https://github.com/RizRiyz/luvus/commit/b1f09c76efa5de1a3a49a17e65a10b63f4d59735), [#462](https://github.com/RizRiyz/luvus/pull/462)).
- **Worktrees:** Use module-provided worktree creation and removal alongside the built-in Git provider ([`51fcfe1`](https://github.com/RizRiyz/luvus/commit/51fcfe1590f077c53cc9f51467f606bf853189e7), [#387](https://github.com/RizRiyz/luvus/pull/387)).
- **UHP:** Exclude externally managed terminals from session restoration with a per-terminal restore policy ([`e351128`](https://github.com/RizRiyz/luvus/commit/e351128cca1878c1b2ee6ab765aa11c05567e51e), [#444](https://github.com/RizRiyz/luvus/pull/444)).
- **Clipboard:** Paste clipboard images on macOS, Wayland, and X11 desktops in addition to Windows ([`eea2b2c`](https://github.com/RizRiyz/luvus/commit/eea2b2ce539a7509815e3c311648115b0f52885c), [#403](https://github.com/RizRiyz/luvus/pull/403)).

- **Search:** Match Unicode case variants consistently and preserve joined characters in file wrapping and highlights ([`0c5ac30`](https://github.com/RizRiyz/luvus/commit/0c5ac30cb9e3686a498521fccdafe99feec1bef0), [#414](https://github.com/RizRiyz/luvus/pull/414)).

- **UHP:** Report process exit codes or signals after final terminal output and distinguish exits from explicit closes ([`8029d9b`](https://github.com/RizRiyz/luvus/commit/8029d9b5e3ed216fbab55bfc672060471c4c07aa), [#438](https://github.com/RizRiyz/luvus/pull/438)).
- **Mission Control:** Explain unavailable usage, expose refresh completion, and calculate burn rates only from comparable samples ([`a16459d`](https://github.com/RizRiyz/luvus/commit/a16459d61ffcc398b23e96b077b73c921cd50b3e), [#455](https://github.com/RizRiyz/luvus/pull/455)).
