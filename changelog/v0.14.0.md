Luvus v0.14.0 adds persistent SSH machines, native Devin, OpenCode 2, Kilo Code, and Antigravity agents, scheduled ORCH automations, faster session controls, keyboard-complete sidebar navigation, and a refreshed visual identity. Existing v0.13.4 settings and sessions remain compatible after upgrading.

## Features

- **Brand:** Use the new gold pixel mark across the app, plugin, website, favicons, and social previews ([`05b7fd7`](https://github.com/RizRiyz/luvus/commit/05b7fd7), [#343](https://github.com/RizRiyz/luvus/pull/343)).
- **Machines:** Save SSH hosts, connect one remote session, and browse its workspaces beside local projects in the native sidebar ([`9b9c477`](https://github.com/RizRiyz/luvus/commit/9b9c477), [#333](https://github.com/RizRiyz/luvus/pull/333)).
- **Agents:** Detect, monitor, resume, and install the Luvus skill for native Devin, OpenCode 2, Kilo Code, and Antigravity CLI sessions ([`48aa5bc`](https://github.com/RizRiyz/luvus/commit/48aa5bc), [#325](https://github.com/RizRiyz/luvus/pull/325), [`6d81fe2`](https://github.com/RizRiyz/luvus/commit/6d81fe2), [#318](https://github.com/RizRiyz/luvus/pull/318), [`c878cab`](https://github.com/RizRiyz/luvus/commit/c878cab), [#313](https://github.com/RizRiyz/luvus/pull/313), [`e94856e`](https://github.com/RizRiyz/luvus/commit/e94856e), [#245](https://github.com/RizRiyz/luvus/pull/245)).
- **Sessions:** Stop, start, and manage named sessions from the selector with keyboard actions and a right-click Stop menu ([`751c0d9`](https://github.com/RizRiyz/luvus/commit/751c0d9), [#311](https://github.com/RizRiyz/luvus/pull/311), [`08cfb6a`](https://github.com/RizRiyz/luvus/commit/08cfb6a), [#270](https://github.com/RizRiyz/luvus/pull/270)).
- **ORCH:** Schedule recurring agent automations, write multiline task briefings, and choose per-agent access when creating work ([`8a20cd0`](https://github.com/RizRiyz/luvus/commit/8a20cd0), [#254](https://github.com/RizRiyz/luvus/pull/254), [`3a8867d`](https://github.com/RizRiyz/luvus/commit/3a8867d), [#304](https://github.com/RizRiyz/luvus/pull/304), [`c4aa123`](https://github.com/RizRiyz/luvus/commit/c4aa123), [#319](https://github.com/RizRiyz/luvus/pull/319)).
- **Pane splitting:** Split new panes automatically along the longer side so wide panes go beside and tall panes stack ([`a59108e`](https://github.com/RizRiyz/luvus/commit/a59108e), [#334](https://github.com/RizRiyz/luvus/pull/334)).
- **Themes:** Choose Rosé Pine, Rosé Pine Moon, Rosé Pine Dawn, Tokyo Night, Baitong, PaperColor, and Paper from Settings ([`5fd2d63`](https://github.com/RizRiyz/luvus/commit/5fd2d63), [#310](https://github.com/RizRiyz/luvus/pull/310)).
- **Git:** Read pull request and issue discussions beside metadata in a split Git tab layout ([`2b1465d`](https://github.com/RizRiyz/luvus/commit/2b1465d), [#246](https://github.com/RizRiyz/luvus/pull/246)).
- **Worktrees:** Open any Git checkout from Open Worktree, not only folders under `~/.luvus/worktrees/` ([`8848356`](https://github.com/RizRiyz/luvus/commit/8848356), [#234](https://github.com/RizRiyz/luvus/pull/234)).
- **Folder picker:** Tab-complete directories in Open Workspace Go to without opening a workspace ([`5b5b831`](https://github.com/RizRiyz/luvus/commit/5b5b831), [#340](https://github.com/RizRiyz/luvus/pull/340)).
- **Keys:** Jump to workspaces 1 through 9 with Prefix+Shift+1 through Prefix+Shift+9 ([`2703907`](https://github.com/RizRiyz/luvus/commit/2703907), [#166](https://github.com/RizRiyz/luvus/pull/166)).
- **Sidebar:** Navigate workspaces and agents by keyboard, hide persistent path labels, and drag the rule between stacked docks ([`e71e832`](https://github.com/RizRiyz/luvus/commit/e71e832), [#278](https://github.com/RizRiyz/luvus/pull/278), [`48023da`](https://github.com/RizRiyz/luvus/commit/48023da), [#279](https://github.com/RizRiyz/luvus/pull/279), [`c47dea5`](https://github.com/RizRiyz/luvus/commit/c47dea5), [#238](https://github.com/RizRiyz/luvus/pull/238)).
- **Agents sidebar:** Limit the dock to the active workspace while keeping All versus Active lifecycle filtering ([`315ac2a`](https://github.com/RizRiyz/luvus/commit/315ac2a), [#268](https://github.com/RizRiyz/luvus/pull/268)).
- **Modules:** Publish bounded agent session titles into the AGENTS sidebar and style dock rows with optional tone and clickable spans ([`96da9f3`](https://github.com/RizRiyz/luvus/commit/96da9f3), [#330](https://github.com/RizRiyz/luvus/pull/330), [`c5141a5`](https://github.com/RizRiyz/luvus/commit/c5141a5), [#266](https://github.com/RizRiyz/luvus/pull/266)).
- **DIFF:** Show per-file additions and deletions at the right edge of the DIFF sidebar ([`f79234f`](https://github.com/RizRiyz/luvus/commit/f79234f), [#243](https://github.com/RizRiyz/luvus/pull/243)).
- **Windows paste:** Paste clipboard images into the focused pane as a staged PNG path ([`2a63855`](https://github.com/RizRiyz/luvus/commit/2a63855), [#317](https://github.com/RizRiyz/luvus/pull/317)).
- **UHP access:** Issue time-limited or process-bound access, rename panes through Control Access, and inspect effective permissions ([`ef9236d`](https://github.com/RizRiyz/luvus/commit/ef9236d), [#231](https://github.com/RizRiyz/luvus/pull/231), [`a27ba77`](https://github.com/RizRiyz/luvus/commit/a27ba77), [#326](https://github.com/RizRiyz/luvus/pull/326), [`0375c40`](https://github.com/RizRiyz/luvus/commit/0375c40), [#302](https://github.com/RizRiyz/luvus/pull/302)).
- **Automation:** Restore active-agent automations after restart and wait until an agent reaches a chosen set of statuses ([`d4befb0`](https://github.com/RizRiyz/luvus/commit/d4befb0), [#276](https://github.com/RizRiyz/luvus/pull/276), [`5db879a`](https://github.com/RizRiyz/luvus/commit/5db879a), [#253](https://github.com/RizRiyz/luvus/pull/253)).

## Improvements

- **Performance:** Keep interaction responsive by sleeping when idle, moving Files and session saves off the app loop, and ingesting scrollback in bounded turns ([`3ab061e`](https://github.com/RizRiyz/luvus/commit/3ab061e), [#263](https://github.com/RizRiyz/luvus/pull/263), [`4da9a49`](https://github.com/RizRiyz/luvus/commit/4da9a49), [#293](https://github.com/RizRiyz/luvus/pull/293), [`97b91e9`](https://github.com/RizRiyz/luvus/commit/97b91e9), [#294](https://github.com/RizRiyz/luvus/pull/294), [`3a1eed8`](https://github.com/RizRiyz/luvus/commit/3a1eed8), [#295](https://github.com/RizRiyz/luvus/pull/295), [`4494d81`](https://github.com/RizRiyz/luvus/commit/4494d81), [#281](https://github.com/RizRiyz/luvus/pull/281)).
- **Agents:** Read usage from local agent reports instead of SQLite ([`c42b78c`](https://github.com/RizRiyz/luvus/commit/c42b78c), [#248](https://github.com/RizRiyz/luvus/pull/248)).
- **Status:** Show a static working marker in the Agents dock and Luvus Bar instead of an animated spinner ([`a93486a`](https://github.com/RizRiyz/luvus/commit/a93486a), [#232](https://github.com/RizRiyz/luvus/pull/232)).
- **UHP:** Fence `agent.keys` to the terminal snapshot returned by `agent.read`, and include a stable workspace id on `agent.list` rows ([`46ec15f`](https://github.com/RizRiyz/luvus/commit/46ec15f), [#328](https://github.com/RizRiyz/luvus/pull/328), [`d631378`](https://github.com/RizRiyz/luvus/commit/d631378), [#264](https://github.com/RizRiyz/luvus/pull/264)).
